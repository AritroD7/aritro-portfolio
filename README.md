# Aritro Dhar - Portfolio Website

A modern, elegant portfolio website showcasing my work in marketing, finance, and technology.

## 🌟 Features

- **Modern Design**: Clean, professional aesthetic with smooth animations
- **Fully Responsive**: Optimized for all devices and screen sizes
- **Multi-Page Layout**: Organized content across Home, About, Projects, and Contact pages
- **Performance Optimized**: Fast loading times and smooth interactions

## 🚀 Pages

- **Home**: Introduction, highlights, and featured projects
- **About**: Detailed background, experience timeline, skills, and values
- **Projects**: In-depth showcase of Finico, EdTech game, and research work
- **Contact**: Multiple ways to get in touch with contact form and FAQ

## 🛠️ Technologies

- HTML5
- CSS3 (Custom Properties, Grid, Flexbox)
- Vanilla JavaScript
- Google Fonts (Inter, Playfair Display)

## 📦 Setup

1. Clone this repository
2. Open `index.html` in your browser
3. No build process required!

## 🎨 Customization

- Colors and theme: Edit CSS variables in `styles.css`
- Content: Update HTML files directly
- Animations: Modify `script.js`
